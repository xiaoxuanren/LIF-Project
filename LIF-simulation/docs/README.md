# Reference Notes

This folder contains project notes that are useful for reference but are not part of the supported top-level execution workflow.

- `SCRIPT_DETAILS.md` — Detailed explanation of the supported simulation and learned-LIF scripts.
- `DATA_STRUCTURE.md` — Notes on saved session and recording structure.
- `LIF_simulation_analysis.md` — Analysis-oriented notes about the simulation outputs and interpretation.
- `hub_neurons_instructions.md` — Reference notes about hub-neuron behavior and related workflow assumptions.
- `learned_lif_model_summary_for_pi.md` — High-level learned-LIF model summary.

The supported workflow entry points remain documented in the repository-root `README.md`, `SCRIPTS_SUMMARY.md`, and `CLAUDE.md`.
